abstrak: "Sistem monitoring kualitas udara dalam ruangan dirancang menggunakan ESP32, sensor debu, sensor DHT, dan sensor gas, dengan data ditransmisikan lewat protokol MQTT ke server via WiFi dan bisa diakses lewat aplikasi berbasis web. Diuji selama 24 jam di dalam rumah, sistem menghasilkan data real-time dengan akurasi sensor DHT22 di atas 96%, sensor debu GP2Y1010AU0F di atas 95%, dan sensor gas MQ-7 di atas 93%."
metodologi: "Rancang bangun sistem IoT berbasis ESP32 dengan sensor suhu/kelembaban, debu, dan gas CO, transmisi data via MQTT, diuji lewat pengambilan sampel 24 jam dan validasi akurasi per sensor."
