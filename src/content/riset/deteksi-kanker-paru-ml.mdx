abstrak: "Penelitian ini mendeteksi kanker paru-paru menggunakan pendekatan Machine Learning dengan metode Artificial Neural Network (algoritma Backpropagation) dan Decision Tree (algoritma C4.5), memakai dataset 'Lung Cancer' dari Kaggle. Dengan pembagian 80% data training dan 20% data test, metode ANN mencapai akurasi 97% (precision 98%, recall 96%, F1-score 97%), sementara Decision Tree mencapai akurasi 96% (precision, recall, dan F1-score masing-masing 96%)."
